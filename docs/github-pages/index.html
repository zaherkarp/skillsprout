How It Works

1
Select your current role

Choose from O*NET occupations or enter a custom profile with self-rated skills (0-4 scale).

2
Get scored recommendations

The engine calculates match % and gap % for every target occupation, then assigns each to Ready Now, Trainable, or Long Reskill.

3
Review your transition report

See BLS employment projections, training paths with costs and timelines, and AI-generated narrative analysis.

Interactive Demo

Try the scoring engine yourself. Select a persona and adjust skill levels to see how recommendations change in real time.

1. Choose your current role

This demo ships with built-in sample profiles so it works entirely client-side - no API keys, no server, no database.

2. Rate your skills

Use 0 (none) to 4 (expert). Values are prefilled from the selected role or persona baseline.

3. Recommendation Buckets

Bucket thresholds: Ready Now (match ≥ 75%, gap ≤ 25%), Trainable (match ≥ 50% or gap 26-55%), Long Reskill (everything else).
